# Demonstration videos

Screen recordings of the running application, one per sprint.

| File | Sprint | Length | Covers |
| --- | --- | --- | --- |
| `sprint-1-demo.mp4` | Sprint 1 (19–23 Oct 2026) | 2:03 | US-01, US-03, US-04, US-06, US-07, US-08, US-09, US-12, US-13, US-20, US-25 |

Recorded against the application running locally: the API on port 5000, the
client on port 5173 and MongoDB on 27017. The figures on screen come from the
development seed (`npm run seed:dev -- --fresh`), not from a real account.

The recordings are compressed with H.264 at full capture resolution so the
text stays readable while the files remain small enough to live in the
repository. They carry no audio track.
